# 🐙 OctoQueue — надёжный планировщик задач для автоматизации

OctoQueue помогает автоматизировать регулярные действия в интернете и избавляет от рутинных операций. Сервис разработан для сценариев, где важно не только запускать задачи по расписанию, но и быть уверенным, что они будут сохранены и выполнены даже после сбоев или перезапуска системы.

В отличие от классического cron, OctoQueue обеспечивает:

* ✅ Гарантию сохранности задач
* ✅ Гарантию доставки и выполнения
* ✅ Устойчивость к перезапускам и временным сбоям
* ✅ Простое развертывание на VPS
* ✅ Подходит для веб-автоматизации, интеграций и фоновых процессов

### Когда использовать OctoQueue

* Регулярный сбор данных и мониторинг ресурсов
* Выполнение HTTP-запросов по расписанию
* Автоматизация бизнес-процессов
* Интеграция внешних сервисов и API
* Запуск фоновых задач и периодических обработчиков

### Почему не cron?

Cron отлично подходит для простых сценариев, однако не предоставляет встроенных механизмов гарантированного хранения и повторной доставки задач. OctoQueue создан для случаев, когда пропущенное выполнение недопустимо и требуется более высокий уровень надёжности.

> Настройте задачу один раз и будьте уверены, что она будет выполнена.

Для максимальной эффективности рекомендуется запускать OctoQueue на VPS или выделенном сервере.
